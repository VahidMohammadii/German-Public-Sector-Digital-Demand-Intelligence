# Metric Definitions — Draft

These definitions are candidates for implementation. Confirm field mapping, grain, and filters against the collected TED data before publishing results.

| Metric | Draft definition | Interpretation note |
|---|---|---|
| Published notice count | Count distinct notice identifiers by publication period and selected filters | Measures notices in the defined extract, not total market demand |
| Award notice count | Count distinct award identifiers by award/publication period | Keep separate from original notice count |
| Recurring buyer count | Count buyers with more than one relevant notice in the selected period | Depends on buyer identifier quality and classification scope |
| Reported award value | Sum reported award values only within a consistent currency and value definition | Do not combine currencies without a documented conversion method |
| Data completeness rate | Non-missing values divided by eligible records for a specified field | Report the denominator and eligibility rule |

No values are reported in this document.
